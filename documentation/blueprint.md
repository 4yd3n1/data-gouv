## Session 65 — at a glance

  - `DeclarationPatrimoine` — one row per HATVP DSP / DSPM / DSPFM PDF. PK is `id` (dossierId derived from filename like `"dsp34805"`), so re-running ingest on the same PDF is idempotent. - **Reverse relation** `PersonnalitePublique.patrimoines DeclarationPatrimoine[]`.
